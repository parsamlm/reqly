# The Reqly name and logo

Reqly's source code is open source under the [MIT License](LICENSE). The Reqly **name**, **icon** and **wordmark** are not covered by that license. The Reqly Authors reserve them, so people can always tell the official Reqly apart from other versions.

This applies to the artwork in [`design/logo/`](design/logo), the app icon built from it, and the name "Reqly" wherever it identifies the app.

## You're welcome to

- Use the name "Reqly" to refer to this project, for example in articles, tutorials, reviews and talks.
- Use the unchanged logo to link to Reqly or write about it, following the [design guidelines](design/GUIDELINES.md#1-logo-and-brand).
- Build and share your own modified version of the code under the MIT License.

## Please don't

- Call a modified or unofficial version "Reqly", or give it a name that could be confused with Reqly.
- Use the Reqly icon or wordmark in a modified version. Give your version its own name and icon.
- Use the name or logo in a way that suggests the Reqly Authors made or endorse your product when they don't.

If you're unsure whether a use is fine, open an issue and ask.
