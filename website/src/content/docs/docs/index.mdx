## Mac and Windows

The two apps work the same way, and these pages cover both. Where the steps differ, choose **Mac** or **Windows** above them. The tabs start on your system, and the docs remember your choice from page to page.

Reqly for Windows is in beta. A few things are on one system only, such as iOS Simulators, which need a Mac. The pages say so where it matters.
