---
title: Keyboard shortcuts
description: Every keyboard shortcut in Reqly.
---

## Capturing

| Shortcut | What it does |
|---|---|
| ⌘R | Start or stop capturing |
| ⌘K | Clear traffic |
| ⇧⌘D | Open the Devices window |

## Requests

| Shortcut | What it does |
|---|---|
| ⌘F | Search requests |
| ⇧⌘C | Copy the URL |
| ⌥⌘C | Copy as cURL |
| ⌘1 to ⌘6 | Show the Overview, Request, Response, Raw, Timing or Messages tab |

## Files

| Shortcut | What it does |
|---|---|
| ⌘N | New request |
| ⌘O | Open a session or a HAR file |
| ⌘S | Save the session |
| ⇧⌘E | Export as HAR |

## Rules

| Shortcut | What it does |
|---|---|
| ⌥⌘R | Show the Rules window |
| ⇧⌘B | Turn breakpoints on or off |
| ⇧⌘T | Turn slow network on or off |
| ⌘↩ | Continue the paused request or response |
| ⌥⌘↩ | Continue everything that's paused |

## Windows

| Shortcut | What it does |
|---|---|
| ⌘0 | Show the main window |
| ⌘, | Settings |
| ⌘? | Reqly Help |

## Elsewhere

| Shortcut | What it does |
|---|---|
| ⌘↩ | Send, in a new request's window |
| ← and → | Fold and unfold a device in the sidebar |
| Delete | Remove the selected rule, or the selected item in a Settings list |
