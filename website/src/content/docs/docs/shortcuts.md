---
title: Keyboard shortcuts
description: Every keyboard shortcut in Reqly, on the Mac and on Windows.
---

Most shortcuts are the same on both systems, with Ctrl on Windows for ⌘ on the Mac, Alt for ⌥, Shift for ⇧ and Enter for ↩. A dash means Windows has no shortcut for it. On both, the menus show shortcuts beside their commands.

## Capturing

| Mac | Windows | What it does |
|---|---|---|
| ⌘R | Ctrl+R | Start or stop capturing |
| ⌘K | Ctrl+K | Clear traffic |
| ⇧⌘D | Ctrl+Shift+D | Open the Devices window |

## Requests

| Mac | Windows | What it does |
|---|---|---|
| ⌘F | Ctrl+F | Search requests |
| ⇧⌘C | Ctrl+Shift+C | Copy the URL |
| ⌥⌘C | Ctrl+Alt+C | Copy as cURL |
| ⌘1 to ⌘6 | Ctrl+1 to Ctrl+6 | Show the Overview, Request, Response, Raw, Timing or Messages tab |

## Files

| Mac | Windows | What it does |
|---|---|---|
| ⌘N | Ctrl+N | New request |
| ⌘O | Ctrl+O | Open a session or a HAR file |
| ⌘S | Ctrl+S | Save the session |
| ⇧⌘E | Ctrl+Shift+E | Export as HAR |

## Rules

| Mac | Windows | What it does |
|---|---|---|
| ⌥⌘R | Ctrl+Alt+R | Show the Rules window |
| ⇧⌘B | Ctrl+Shift+B | Turn breakpoints on or off |
| ⇧⌘T | Ctrl+Shift+T | Turn slow network on or off |
| ⌘↩ | Ctrl+Enter | Continue the paused request or response |
| ⌥⌘↩ | Ctrl+Alt+Enter | Continue everything that's paused |

## Reqly's windows

| Mac | Windows | What it does |
|---|---|---|
| ⌘0 | — | Show the main window |
| ⌘, | Ctrl+, | Settings |
| ⌘? | F1 | Reqly Help, which on Windows opens these pages in your browser |
| ⌘W | Ctrl+W | Close the window |
| ⌘Q | Ctrl+Q | Quit Reqly |

On Windows, to show the main window again, double-click Reqly's icon in the notification area, choose **Open Reqly** in its panel, or open Reqly from the Start menu. While the icon shows, closing the window leaves Reqly running there. Ctrl+Q quits it.

## Elsewhere

| Mac | Windows | What it does |
|---|---|---|
| ⌘↩, or Return in the URL field | Ctrl+Enter, or Enter in the URL box | Send, in a new request's window |
| Delete | Delete | Remove the selected rule, or the selected item in a Settings list |

On the Mac, ← and → fold and unfold a device in the sidebar.

On Windows:

- To fold a device in the sidebar, click the arrow beside it.
- In **Settings › HTTPS**, Delete doesn't remove a host. Click the trash button beside it.
- Esc closes the notification-area panel.
