# Reqly for iPhone and iPad

[Phase 3](../ROADMAP.md#phase-3--reqly-for-iphone-and-ipad) of the roadmap: a companion app that sends an iPhone's or iPad's traffic to Reqly on a Mac or Windows PC. It hasn't started yet.

The app doesn't run Reqly's engine. It pairs with the desktop app and sends traffic to it through a local VPN. Its code goes in this folder.
