# Reqly for Android

[Phase 4](../ROADMAP.md#phase-4--reqly-for-android) of the roadmap: the same companion app for Android phones and tablets, which also tells Reqly which app made each connection. It hasn't started yet.

The app doesn't run Reqly's engine. It pairs with the desktop app and sends traffic to it through a local VPN. Its code goes in this folder.
